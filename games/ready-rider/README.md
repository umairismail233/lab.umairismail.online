# Ready Rider Game v3

A mobile first training game for courier and parcel delivery riders, built in the Learning Games Lab. It walks a rider through one full working shift: matching and scanning parcels at the hub, loading in a safe order, pre ride checks, road hazard spotting, route planning, respectful customer calls, door handover with COD cash and exact change, customer not available and refusal handling, seller pickup, scam spotting, money sense, and end of day cash reconciliation back at the hub.

Missions are picture first and play in English or Urdu. A readiness report at the end records first attempt scores, mistakes by skill, and whether the rider meets the pass standard. It is a training game, not a licence or a physical certificate.

Live game: https://ready-rider-game-v3.pages.dev

Plain HTML, CSS and JavaScript in one page. Open index.html in a browser to play; there is no build step.
